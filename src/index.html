MCP server

Connect your AI agent to Sevalla.

Deploy, debug and manage your applications, databases and static sites from Claude, ChatGPT, Cursor, VS Code or any other MCP client.

Endpoint

  • Streamable HTTP
  • OAuth sign-in
  • 27 tools
Documentation API reference GitHub

Set up your client

Claude Code

Run this in your terminal, then run /mcp in Claude Code and choose Authenticate to sign in to Sevalla. 

$ claude mcp add --transport http sevalla https://mcp.sevalla.com/mcp

Cursor

Install with the button, or add this to .cursor/mcp.json in your project. Cursor asks you to sign in to Sevalla the first time it uses a tool.

Add to Cursor 
{
  "mcpServers": {
    "sevalla": {
      "url": "https://mcp.sevalla.com/mcp"
    }
  }
}

VS Code

Install with the button, or add this to .vscode/mcp.json in your workspace. VS Code asks you to sign in to Sevalla the first time it uses a tool.

Add to VS Code 
{
  "servers": {
    "sevalla": {
      "type": "http",
      "url": "https://mcp.sevalla.com/mcp"
    }
  }
}

Codex

Run this in your terminal, or add the block below to ~/.codex/config.toml. Codex asks you to sign in to Sevalla the first time it uses a tool. 

$ codex mcp add sevalla --url https://mcp.sevalla.com/mcp
[mcp_servers.sevalla]
url = "https://mcp.sevalla.com/mcp"

GitHub Copilot

Add this to the MCP configuration of the Copilot coding agent, in your repository's Settings → Copilot → Coding agent. 

{
  "mcpServers": {
    "sevalla": {
      "type": "http",
      "url": "https://mcp.sevalla.com/mcp",
      "tools": ["*"]
    }
  }
}

Factory Droid

Run this in your terminal, then run /mcp in Droid to sign in to Sevalla.

$ droid mcp add sevalla https://mcp.sevalla.com/mcp --type http

opencode

Add this to opencode.json in your project or in ~/.config/opencode/.

{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "sevalla": {
      "type": "remote",
      "url": "https://mcp.sevalla.com/mcp",
      "enabled": true
    }
  }
}

Other clients

Most MCP clients take this shape. Point any client that supports Streamable HTTP at the endpoint; it signs in to Sevalla with OAuth on first use. 

{
  "mcpServers": {
    "sevalla": {
      "url": "https://mcp.sevalla.com/mcp"
    }
  }
}
